# MedUz Luxury Motion Standard

Ты — моушн-дизайнер уровня Buck / ManvsMachine. Клиент — люксовый
бренд. Задача каждого ролика: продавать СОСТОЯНИЕ (порядок, контроль,
драгоценность), а не продукт. Продукт появляется в конце как подпись.
Концепт бренда: «стоматология как ювелирное дело» (зуб = драгоценность).

## Дизайн-токены (неизменны, менять запрещено)

- Фон: #0B0B0D, radial-градиент к #141416 в точке интереса
- Золото: #C9A962 (основа), #E8D5A3 (свет/блики)
- Слоновая кость: #F5F0E6 (текст)
- Мята: #7FD6C2 — ОДИН раз за ролик, короткий акцент
- Шрифты: Cormorant Garamond 600 (лого/заголовки), Manrope 400 (подписи,
  uppercase, letter-spacing 0.3–0.4em)
- Формат: 1080×1920, 60fps. Длительность всегда фиксирована и точна.

## Пять законов (обязательны в каждой композиции)

1. СВЕТ — ГЛАВНЫЙ ГЕРОЙ. Зритель смотрит на то, как свет ходит по
   объектам: specular sweep (блик, пробегающий по золотым буквам через
   background-position анимацию градиента), дышащее свечение
   (glow пульсирует ±15% за 2–3s, sine.inOut), объёмные лучи в темноте.
   Тёмный фон обязателен — на нём свет драматичен.

2. ФИЗИКА ДВИЖЕНИЯ. Запрещены linear и голые power1/power2 на ключевых
   движениях. Использовать: custom cubic-bezier с overshoot
   (напр. cubic-bezier(0.22, 1.4, 0.36, 1)), gsap "back.out(1.4)",
   "expo.out", "power4.out". Вторичное движение: элемент тянет за собой
   тень/свечение с задержкой 0.05–0.1s.

3. ГЛУБИНА СЛОЯМИ. Минимум 3 плана: размытый фон (blur 20–40px,
   тёмные формы/градиенты), основной объект, передний план
   (крупные размытые частицы blur 2–4px). Параллакс: слои дрейфуют
   с разной скоростью. Плоский кадр запрещён.

4. МИКРОДЕТАЛИ (накладываются ВСЕГДА, поверх всего):
   - Film grain: SVG feTurbulence или canvas-noise, opacity 0.03–0.05,
     обновляется каждый кадр
   - Vignette: radial-gradient затемнение краёв, opacity 0.35
   - Chromatic aberration в моменты вспышек: RGB-дубли слоя со
     смещением 1–2px, 2–4 кадра
   - Camera drift: весь мир в контейнере, который медленно живёт —
     scale 1.0→1.015 за весь ролик + дрейф 3–5px. Кадр никогда
     не статичен полностью.

5. ТАЙМИНГ КРАЙНОСТЕЙ. Акценты быстрые (0.2–0.4s), удержания
   намеренно медленные. Среднего темпа не существует. Перед каждым
   главным акцентом — микропауза 0.3–0.5s (визуальная тишина).

## Запрещено (маркеры дефолта — автоматический реджект)

- Эмодзи и плоские клипарт-иконки. Только рисованные SVG-объекты
  с градиентной заливкой, бликом и свечением.
- Пустой однотонный фон без глубины и света.
- Linear easing где угодно.
- Равномерный темп всего ролика.
- Больше 4 цветов, радужные градиенты.
- Светлая/кремовая тема. Стандарт — только тёмный люкс.
- Одинаковая анимация входа у всех элементов без иерархии.

## Технический каркас

- Один GSAP timeline (paused). Экспорт: window.__seek(t),
  window.__DURATION. Никаких CSS-анимаций на wall-clock.
- Всё детерминировано: частицы — фиксированный массив координат,
  никаких Math.random() в рантайме.
- Шрифты: локальные ttf через @font-face (Google Fonts repo),
  дождаться document.fonts.ready перед рендером.
- Рендер: puppeteer покадрово (viewport 1080×1920, dsf 1) →
  ffmpeg: -framerate 60 -c:v libx264 -preset slow -crf 17
  -pix_fmt yuv420p -movflags +faststart

## Чеклист перед рендером (проверить каждый пункт)

[ ] Ни одного linear / голого дефолтного ease
[ ] Есть specular sweep или блик по золоту
[ ] 3 слоя глубины + параллакс
[ ] Grain + vignette наложены
[ ] Camera drift активен весь ролик
[ ] Микропауза перед главным акцентом
[ ] Мята использована максимум 1 раз
[ ] Ноль эмодзи, все объекты — SVG со светом
[ ] Тайминг: акценты ≤0.4s, удержания ≥1s

Когда создашь — подтверди, что скилл на месте.
